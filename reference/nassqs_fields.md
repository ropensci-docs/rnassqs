# Deprecated: Return list of NASS QS parameters.

Deprecated. Use
[`nassqs_params()`](https://docs.ropensci.org/rnassqs/reference/nassqs_params.md)
instead.

## Usage

``` r
nassqs_fields(...)
```

## Arguments

- ...:

  a parameter, series of parameters, or a list of parameters that you
  would like a description of. If missing, a list of all available
  parameters is returned.
