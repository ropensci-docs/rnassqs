- [`nassqs_record_count()`](https://docs.ropensci.org/rnassqs/reference/nassqs_record_count.md)
  : Get a count of number of records for given parameters.

- [`nassqs_yields()`](https://docs.ropensci.org/rnassqs/reference/nassqs_yields.md)
  : Get yield records for a specified crop.
